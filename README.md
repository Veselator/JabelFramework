# Jabel Framework + «1000 Monkeys»

Unity 6 (URP 2D). Фреймворк для кликеров **Jabel** и демо-игра **1000 Monkeys** в одном проекте, но в раздельных сборках:

| Папка | Сборка | Что внутри |
|---|---|---|
| `Assets/Scripts/Jabel/Runtime` | `Jabel.Runtime` | фреймворк (не знает о демо) |
| `Assets/Scripts/Jabel/Editor` | `Jabel.Editor` | блочный редактор JabelScript, генератор сцены, валидатор, отладка |
| `Assets/Scripts/Demo/Runtime` | `OneKMonkeys.Runtime` | игровые системы демо |
| `Assets/Scripts/Demo/Editor` | `OneKMonkeys.Editor` | генератор демо-сцены и данных |
| `Assets/Localization/Jabel`, `.../Demo` | — | CSV-таблицы переводов (`key,en,ru`) |
| `Assets/Shaders/Demo` | — | универсальный шейдер обезьян |
| `Assets/Data/Demo` | — | ScriptableObject-данные демо (генерируются) |

## Быстрый старт

- **Tools → 1000 Monkeys → Build Demo Scene** — собирает `Assets/Scenes/Demo/OneKMonkeys.unity` (данные, префабы, сцену). Нажмите Play.
- **Tools → Jabel → Build Clicker Scene** — «Построить сцену кликера»: пустой кликер с кнопкой, магазином тестовых предметов, HUD, тостами и офлайн-попапом.
- **Tools → Jabel → Validate Configs** — проверка формул, неизвестных имён, дубликатов id, пропущенных переводов.
- **Tools → Jabel → Formula Reference** — справочник функций, «песочница» формул и живые значения в Play Mode.
- **Tools → Jabel → Debug** — удалить сохранение, симулировать 1 ч / 8 ч отсутствия, +1M денег, скриншот 1920×1080.
- Юнит-тесты фреймворка: `Assets/Scripts/Jabel/Tests` (Window → General → Test Runner → EditMode).
- Уже сгенерированы: `Assets/Scenes/Demo/OneKMonkeys.unity` (первая в Build Settings) и `Assets/Scenes/Jabel/ClickerTemplate.unity`.

## Архитектура Jabel

```
ClickerManager (MB, композиционный корень)
 ├─ EventBus          — типизированные события: TickEvent, ActiveBuffBoughtEvent, PassiveBuffBoughtEvent,
 │                      AnyBuffBoughtEvent, FunctionCalledEvent (OnFunction), VariableChangedEvent, ClickEvent,
 │                      BuffInstanceCreated/LevelUp, BuffUnlocked, OfflineProgress, Notification, GameStarted...
 ├─ VariableStore     — глобальные переменные (BigNumber) + derived-значения (формулы с кэшем)
 ├─ BuffSystem        — владение, цены, требования, инстансы с уровнями, тики активных баффов
 ├─ FunctionRegistry  — мост «блок Call function → C#-обработчик / FunctionListener / шина»
 ├─ SaveSystem        — JSON-сохранения, бэкап, миграции, ISaveParticipant для игровых систем
 └─ Loc               — локализация (CSV, плюралы, локализованные суффиксы чисел)
```

- **ClickerConfig** (SO) — вся игра в данных: длительность тика, переменные, derived-формулы, пассивные/активные баффы, скрипты `OnStart`, `OnNewGame`, `OnClick`, `OnTick`, `OnReturn`, настройки сохранения и офлайна.
- **BaseBuff** (SO) → **PassiveBuff** / **ActiveBuff**: иконка, название, тег, описание, цена (`BuffCost`), лимит, требования, `OnBought`. У ActiveBuff — `period` (тики, формула) и `OnTick`; опционально **инстансы**: каждая единица со своим уровнем, таймером, сидом и переменными (обезьяны).
- Все UI-компоненты наследуются от `JabelBehaviour` и подключаются к сессии после загрузки (`OnBind/OnUnbind`).

### JabelScript — блочное программирование в инспекторе

Скрипт — список блоков (`[SerializeReference]`), в инспекторе это цветные сворачиваемые блоки с кнопками ▲▼⧉✕ и меню «+ Add block». Новый блок = новый класс-наследник `JabelBlock` с атрибутом `[JabelBlock("Категория/Имя")]`, редактор подхватит его сам.

| Категория | Блоки |
|---|---|
| Variables | Set, Modify (+ − × ÷ ^ min max), Declare (local / global / instance) |
| Flow | If, Chance, Repeat, While, Break, Stop, Comment |
| Functions | Call function (именованные аргументы, результат в local), Run script asset (подпрограммы) |
| Buffs | Grant, Buy, Unlock |
| Game | Reset run (престиж), Save |
| Feedback | Notify (тост с локализацией), Play sound, Log (с `{формулами}`) |

Все числовые поля — **формулы** (`JabelFormula`): `10 * 1.15 ^ count('monkey')`, `playerLevel >= 5 ? 2 : 1`, `min(a, b)`, `rate('money')`, `table('curve', level)`. Формула компилируется один раз, подсвечивается красным при ошибке.

### Что фреймворк решает из типичных проблем кликеров

| Проблема | Решение в Jabel |
|---|---|
| Переполнение double (1e308) и точность | `BigNumber` (мантисса × 10^exp), все экономические значения |
| Форматирование «1.5M» / «1,5 млн» | `NumberFormatter`: short/scientific/engineering, суффиксы из локализации, aa/ab после дециллионов |
| Экспоненциальные цены, «купить x10 / максимум» | `BuffCost`: геометрическая прогрессия с формулой суммы и max-affordable в закрытой форме |
| Сохранения ломаются при ребалансе | derived-значения пересчитываются из `count('id')`, а не «применяются» при покупке |
| Порядок бонусов (+ и ×) | один читаемый derived-формулой на характеристику |
| Офлайн-прогресс, подмена часов | UTC-время, защита от отрицательного времени, лимит и эффективность — формулы; симуляция батчами (`batch`), отчёт «Пока вас не было» |
| Возврат из фона на мобилке | `OnApplicationPause` сохраняет и засчитывает отсутствие как офлайн |
| Просадки FPS / вкладка в фоне | фиксированный тик, лимит тиков за кадр, остаток схлопывается в батч |
| Тысячи генераторов | активные баффы исполняются батчем; demo анимирует только видимые станции |
| Порча файла при выключении | запись во временный файл + `.bak`, чтение с отката |
| Временные бусты «слетают» после загрузки | `countdown`-переменные (уменьшаются каждый тик, сохраняются) |
| Прогрессивное раскрытие магазина | требования `переменная ≥ значение` с авто-подсказкой, видимость `WhenUnlocked` |
| Опечатки в данных | валидатор, подсветка формул, превью переводов в инспекторе |
| Престиж | `Reset run`: Run-переменные и баффы сбрасываются, Permanent остаются |
| Локализация «1 обезьяна / 2 обезьяны / 5 обезьян» | плюралы `key#one/#few/#many/#other` по правилам CLDR |

## 1000 Monkeys

- **Главный экран**: слева ваш компьютер (клик — экран кликера), справа ряд обезьян, в конце — слот «Нанять» с ценой. Камера листается перетаскиванием, колесом, A/D, скроллбаром. Верхняя панель: уровень + прогресс строк, деньги, число обезьян, улучшения, язык, выход.
- **Экран кликера**: монитор с кодом, клик пишет символы; цифры и буквы плавно «вылетают», пробелы/пунктуация/переводы строк появляются сразу, синтаксис подсвечивается, код прокручивается под маской; из точки клика сыплются частицы и `$` пропорционально доходу.
- **Экономика** (всё в `Assets/Data/Demo/ClickerConfig.asset`): $0.1 за символ, $10 × уровень за повышение уровня, строк на уровень: 20, 50, 125… (×2.5). Базовая обезьяна — 1 символ раз в 20 тиков (тик = 0.25 с). Цена найма растёт геометрически.
- **Обезьяны**: 20 уровней, у каждого своё звание и эффект шейдера `OneKMonkeys/MonkeyEffects` (контур, свечение, блик, пульс, желе, голограмма, радуга, искры, золото, глитч, хроматика, электричество, огонь, призрак, галактика, растворение, радужный контур, нимб…), случайный цвет в диапазоне уровня, живые глаза (моргание, взгляд), покачивание, дыхание, «печать», всплывающий текст дохода. Клик по обезьяне — панель прокачки.
- **Улучшения**: механическая клавиатура, вкладка Stack Overflow, премиальные бананы, печатная машинка (активный бафф), **большой экран** (монитор на стене, прикреплён к камере — можно кликать с главного экрана), резиновая уточка (криты), двойной эспрессо, код-ревью, автодополнение, опенспейс, git blame (офлайн), наставничество, режим Шекспира. Многие открываются с определённого уровня.
- Вся «логика написания кода» (деньги, строки, повышения уровня, уведомления) — это JabelScript `onWritten` на объекте **CodeWriter**, а C# отвечает только за продвижение курсора по базе кода.
